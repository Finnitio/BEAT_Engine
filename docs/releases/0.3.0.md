# BEAT Engine 0.3.0

- Support CPU coupled deployment solves using exported speaker ROMs, including
  multiple speaker packages, cached field evaluation, and warm-start sweeps.
- Add optional complex radiated-pressure contributions for coupled interfaces,
  preserving full spatial flux, scattering, phase, and the combined response.

Existing worker protocols and supported request/result schemas remain compatible.
CUDA deployment solving remains supported. Consumers must explicitly adopt this
release through a tested wheel URL and SHA-256 dependency update.

Numerical changes are covered by their feature tests and the standalone Julia
reference gate. Final artifact hashes and hardware qualification results will be
recorded in the GitHub release before publication.
